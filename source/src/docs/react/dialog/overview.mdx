# Dialogs

Dialog can be displayed easily by [`openDialog`](:):

```tsx
openDialog(options)
```

<BasicExample />

> [`openDialog`](:) is introduced as a shorthand in 0.7.0. Before that, use [`createDialog`](:) seeing the next section.

## Manual control

To manually open or close dialog, you can use [`createDialog`](:):

```javascript
const dialog = createDialog(options);
dialog.open()
dialog.close()
```
