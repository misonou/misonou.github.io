# useLanguage

Returns the current language, and refresh the component when the language has changed.

> If [`useTranslation`](:) is already used in a component, there is no need to
  use `useLanguage` hook.

## Syntax

```javascript
useLanguage()
```

<ImportHint
    name="useLanguage"
    module="brew-js-react"

### Return value

Current language.
