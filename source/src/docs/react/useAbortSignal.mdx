# useAbortSignal

Returns a abort signal that is aborted when the component is unmounted.

## Syntax

```javascript
useAbortSignal()
useAbortSignal(deps)
```

### Parameters

<dl>
    #### `deps` <Badge.Version />
    A list of dependencies that will trigger the abort signal when changed.

</dl>

### Return value

An `AbortSignal` object.
