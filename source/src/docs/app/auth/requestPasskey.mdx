# requestPasskey

Requests an existing passkey.

It is a wrapper of `CredentialsContainer.get` that transforms base64-encoded values to
array buffers for use with the Credential Management API and back to base64-encoded values for transmission to server.


## Syntax

```javascript
requestPasskey(options)
requestPasskey(options, signal)
```

<ImportHint
    name="requestPasskey"
    module="@misonou/brew-extension-auth/util"
    require="default.Auth.requestPasskey"
    global="brew.Auth.requestPasskey"
/>

### Parameters

<dl>
    #### `options`
    Configuration options received from server for passkey request.

    #### `signal` <Badge.Optional />
    An optional signal object to abort the passkey request.

</dl>

### Return value

A promise that resolves to the result of the passkey request that can be sent to server for verification.

## Example

```javascript
import { createApiClient } from "brew-js/util/fetch";
import { requestPasskey } from "@misonou/brew-extension-auth/util";

const client = createApiClient(BASE_URL);
const options = await client.get('/api/login/options');
const payload = await requestPasskey(options);
await client.post('/api/login/verify', payload);
```
