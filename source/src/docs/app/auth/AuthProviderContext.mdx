## Instance properties

### `AuthProviderContext.interaction` <Badge.ReadOnly /> <Badge.Version />

Specifies the preferred way to login. It can be one of the following value:

<dl>
    #### `redirect`
    #### `popup`
</dl>

### `AuthProviderContext.redirectUri` <Badge.ReadOnly />

Fully qualified URL for redirection after logging in or out through external authentication provider.

## Instance methods

### `AuthProviderContext.challenge()`

```javascript
challenge(challenge, value)
challenge(challenge, value, callback)
```

Initiates a login challenge, typically when multi-factor authentication is required.

### Parameters

<dl>
    #### `challenge`
    Type of challenge to initiate.

    #### `value`
    Value associated with the challenge.

    #### `callback`
    A callback function to handle the challenge response. It should throw or returns a rejected promise if the response is invalid, in this case, caller can retry with another response. To end the challenge without retry, callback should return a dedicated value and handle outside of the callback.

</dl>

### Return value

Returns a promise that resolves to
- when `callback` is not provided, the value being passed to [`AuthChallenge.continueWith`](:) or
- when `callback` is provided, the value returned by the callback.

### `AuthProviderContext.revokeSession()`

```javascript
revokeSession()
revokeSession(accountId)
```

Revokes login session, typically when user has signed out elsewhere.

It will emit a handleable `sessionEnd` event before logging out completely.
It has no effect if user is not currently logged in with this provider or the `accountId` parameter does not match current one.

#### Parameters

<dl>
    #### `accountId` <Badge.Optional />
    Account to logout. If not specified, the current account will be logged out.

</dl>
