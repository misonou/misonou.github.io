### Supported features in the selected version

Flag in the table below represents the property name on [`Parser.supports`](:) object.

<SupportTable>

- `nestedDataPath`
  Nested parenthesized data paths e.g. `$(foo.$(bar.baz))`

- `poundVariableInPipe`
  `#index`, `#count` and its shorthand variable in pipe function e.g. `arr where [ #index == #count - 1 ]`

</SupportTable>
