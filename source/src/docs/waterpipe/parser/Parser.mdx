### `Parser.isValidProperty()`

Checks whether a property is valid for an input object.

A valid property name can 1) appear as a single traversal step in a data path, and 2) when unquoted as the first token in
an expression, or as an argument to a function where evaluation mode is `auto`,
the token is interpreted as a property access on the current input object.

A property is consider valid on a given input when all of the following criteria is met:
- input is an object
- property exists on the object
- property evaluates to value other than function
- property name is a valid property name.

```javascript
isValidProperty(input, prop)
```

#### Parameters

<dl>
    #### `input`
    The input object.

    #### `prop`
    The property name.

</dl>

### `Parser.isValidPropertyName()`

Checks whether a name is a valid property name.

A valid property name should not contain whitespace or dot (`.`) character and
should not start with dollar sign (`$`) or double quote (`"`) character.

```javascript
isValidPropertyName(prop)
```

#### Parameters

<dl>
    #### `prop`
    The property name.

</dl>

```javascript

```

#### Parameters

<dl>

    The expression string to parse.

    #### `input` <Badge.Optional />
    Optional input data for evaluation.

    #### `globals` <Badge.Optional />
    Optional global variables.

</dl>

#### Return value

A [`RootExpression`](:) object representing the parsed AST.

### `Parser.requireEscape()`

Checks whether a string requires escaping to be a proper token in an expression.

A string value requires escaping if it is an empty string, contains whitespace,
starts with a backtick character, or is wrapped by double quotes (`"`).

```javascript
requireEscape(value)
```

#### Parameters

<dl>
    #### `value`
    Unescaped string representing the constant.

</dl>

### `Parser.unescapeConstant()`

Unescapes a constant value.

It unescapes double-quoted strings by removing the surrounding quotes and unescaping inner quotes;
or remove preceding backtick character from backtick-escaped strings. If the string is not quoted or backtick-escaped,
it is returned as-is.

Similar to [`Parser.parseConstant`](:) but does not convert the value to other types.

```javascript
unescapeConstant(value)
```

#### Parameters

<dl>
    #### `value`
    The string to unescape.

</dl>
