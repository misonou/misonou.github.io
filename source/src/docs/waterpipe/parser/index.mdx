# Waterpipe parser

A parser for [waterpipe](/docs/waterpipe/using-waterpipe) template engine.

> **Important** It is recommended to use the same minor version of `waterpipe-parser` as `waterpipe` library.

## Features

- [Parsing expressions](/docs/waterpipe/parser/parsing-expressions) &mdash; Parsing expressions into AST
- [Visiting expressions](/docs/waterpipe/parser/visiting-expressions) &mdash; Visiting expression AST nodes
- [Evaluating expressions](/docs/waterpipe/parser/evaluating-expressions) &mdash; Evaluating expressions with context and scopes
- [Diagnostics](/docs/waterpipe/parser/diagnostics) &mdash; Getting warnings and errors for expressions
- [Code suggestions](/docs/waterpipe/parser/code-suggestions) &mdash; Getting code completions for expressions

> Currently only expression is supported. Parsing waterpipe template is not supported.
