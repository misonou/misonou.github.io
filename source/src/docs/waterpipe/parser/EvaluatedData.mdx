## Instance properties

### `EvaluatedData.expandable`

Gets whether nested data paths can exist.

### `EvaluatedData.unionOf` <Badge.ReadOnly />

Gets an array of possible values. If only a single value exists, undefined is returned.

### `EvaluatedData.value` <Badge.ReadOnly />

Gets the evaluated value. If multiple possible values exist, the first one is returned.

## Instance methods

### `EvaluatedData.asIterated()`

```javascript
asIterated()
```

Gets a new instance representing all possible values iterated from this data.

### `EvaluatedData.expandDataPaths()`

```javascript
expandDataPaths()
expandDataPaths(prefix)
```

Gets all descendant data paths recursively.

#### Parameters

<dl>
    #### `prefix` <Badge.Optional />
    Prefix for iterated data paths. If a callback is supplied, it will be called for each data path to prefix it with the returned string.

</dl>

### `EvaluatedData.getDataPaths()`

```javascript
getDataPaths()
getDataPaths(prefix)
```

Gets child data paths for this data.

#### Parameters

<dl>
    #### `prefix` <Badge.Optional />
    Prefix for iterated data paths. If a callback is supplied, it will be called for each data path to prefix it with the returned string.

</dl>

### `EvaluatedData.getProperty()`

```javascript
getProperty(name)
```

Evaluates the property value by name. If the property is not valid, `EvaluatedData.empty` is returned.

### Parameters

<dl>
    #### `name`
    Property name.

</dl>

### `EvaluatedData.hasProperty()`

```javascript
hasProperty(name)
```

Checks whether the data has a property with the specified name.

#### Parameters

<dl>
    #### `name`
    Property name.

</dl>

### `EvaluatedData.toString()`

```javascript
toString()
toString(options)
```

Converts the data to a string representation.

#### Parameters

<dl>
    #### `options` <Badge.Optional />
    Formatting options.

    <dl>
        #### `listObjectMembers` <Badge.Optional />
        Specifies whether to append object members in the formatted string.

        #### `listUnionValues` <Badge.Optional />
        Specifies whether to append union values in the formatted string.

        #### `maxLength` <Badge.Optional />
        Specifies the maximum length of the formatted string.
    </dl>
</dl>


## Static properties

### `EvaluatedData.empty` <Badge.ReadOnly />

A default instance representing the undefined value.
