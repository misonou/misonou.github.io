# Code suggestions

The [`CodeSuggestionContext`](:) class provides code suggestions for a given expression and position.

It gives suggestions based on the context at the given position:

- In or expecting an argument expression:
  - **Pipe suggestions**: Conversion of current argument to a nested pipe argument.
  - **String suggestions**: Conversion of current token to a double-quoted constant value.
  - **Path suggestions**: Available data paths.

- In or expecting a function name:
  - **Function suggestions**: Available pipe functions that accepts the current input value.

> **Important** To get accurate code suggestions, make sure to add function definitions for custom pipe functions.
  See [Custom functions](/docs/waterpipe/parser/custom-functions) section for more details.


```javascript
const parser = Parser.default;
const expr = parser.parseExpression('arr', { arr: [1, 2, 3] }, { foo: { bar: {} } })
parser.getCodeSuggestionContext(expr, 0).suggestions
// -> [ { type: 'pipe', value: '[ arr ]', ... }, ... ]
```

Data path masked by variable scopes are automatically resolved as prefixed with correct scope resolutions:

```javascript
const expr = parser.parseExpression('', { foo: 1 }, { foo: 2 });
parser.getCodeSuggestionContext(expr, 0).suggestions
// -> [ { type: 'path', value: '[  ]', ... }, ... ]
```

## Applying code suggestions

Uses [`CodeSuggestionContext.createCodeEdit()`](:) function to create code edits based on the current context.

```javascript
const expr = parser.parseExpression('arr join ""');
const context = parser.getCodeSuggestionContext(expr, 0);
context.editMode // -> 'replace'
context.createCodeEdit('[ arr ]')
// -> { value: '[ arr ]', range: [0, 3], selectionAfter: [5, 5] }
```

The `value` will replace original text in the `range`, and the cursor will be placed at `selectionAfter` position after applying the edit.


## Documentations

Although not directly consumed by the parser library, it provides a way to get function documentations for code suggestions.

```javascript
getFunctionDocumentation('en', 'where', [{ kind: 'pipe' }])
```

It will return a [`FunctionDocumentation`](:) object like following:

```javascript
{
    name: 'where',
    description: 'Filters an object, list or table by condition.',
    args: [
        {
            position: 0,
            kind: 'pipe',
            name: 'condition',
            description: 'An expression that returns true or false'
        }
    ]
}
```
